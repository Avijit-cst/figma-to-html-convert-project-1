## 📌 Project Overview

KINETIC is a stylish and professional sports footwear landing page built from a Figma design using pure HTML and CSS.  
The project focuses on delivering a premium user experience with a clean layout, responsive design, and modern UI aesthetics.

This project demonstrates frontend development skills including layout structuring, responsive web design, typography management, and modern visual presentation.
